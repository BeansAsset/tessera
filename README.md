# Tessera

Unlock your Linux laptop with Face ID on your iPhone, without installing an
app on the phone. Your password keeps working as before; this only adds a
second way in.

In ancient Rome a host and a guest broke a token in two, a *tessera
hospitalis*, and each kept a half. Whoever later brought the matching half was
known as a friend. Tessera works the same way: the laptop keeps one half (a
public key), your iPhone keeps the other (a passkey that only Face ID can
use), and only a match opens the lock screen.

**Status: early.** This repository currently holds a test page that checks
the iPhone side works. The laptop side isn't here yet.
