Set up Tessera

Two shortcuts, once. Tessera itself needs no app.

  1. The “Tessera” shortcut

    In Shortcuts, tap + and name it Tessera. Add these two actions:

    • Get Contents of URL, with this address:
    • Open URLs. It fills in Contents of URL by itself.

  2. The “Tessera Reply” shortcut

    Tap + again and name it Tessera Reply. Add:

    • Get Contents of URL, with this address:
    • Tap the arrow on that action: set Method to POST, Request Body to File, and the file to Shortcut Input.
    • Show Notification, with Contents of URL.

  3. Pair

    On the laptop, press Pair, then run Tessera here.
