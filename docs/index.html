Set Up Tessera

Make two shortcuts in the Shortcuts app. You only do this once.

Shortcut 1: Tessera

Tap + and name the shortcut Tessera.
Add Get Contents of URL with this address:
Add Open URLs. It uses Contents of URL by itself.

Shortcut 2: Tessera Reply

Tap + and name it Tessera Reply, spelled exactly so.
Add Get Contents of URL with this address:
Tap the arrow on that action. Set Method to POST and Request Body to File, then set the file to Shortcut Input.
Add Show Notification and set its text to Contents of URL.

Tessera Reply runs by itself after Face ID. You don't need to tap it.

Then

On the laptop, choose Pair iPhone, then run Tessera here.

Tessera

Unlock your Linux laptop with Face ID on this iPhone. Run the Tessera shortcut to begin.
